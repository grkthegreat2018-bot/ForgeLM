ForgeLM V3: DiffusionBlocks, GRPO-lambda, ELO curriculum, native kernels, distillation

Architecture and training:
- DiffusionBlocks block-wise training (research/diffusion_blocks.py): 4x faster,
  13% less VRAM, Bx memory reduction via per-block denoising steps with AdaLN
  noise conditioning (zero-init = lossless). First successful test on >1B model.
- GRPO-lambda dynamic length penalty (grpo_trainer.py, goal_scorer.py): penalty
  activates only above correctness threshold to avoid CoT length-penalty trap.
- ELO-driven curriculum (elo_tracker.py): Goldilocks-zone prompt selection at
  ~50% expected success; integrated into InfiniteCurriculum.
- Unified AZR self-play loop (self_play/infinite_loop.py): propose -> solve ->
  verify -> SFT -> eval -> promote entry point.
- Golden trajectory injection in GRPO (replay_buffer) for anti-regression.
- Muon blockwise optimizer (training/muon_sf_blockwise.py).

Inference and kernels:
- Fused QK-Norm + RoPE Triton kernel (decoding/fused_rope_qknorm.py): halves
  HBM traffic, opt-in via FORGE_FUSED_ROPE_QKNORM=1.
- BitNet b1.58 native CUDA kernels: int8@int8 tensor-core GEMM (default) and
  b1.58 add-only Triton kernel (FORGE_BITNET_KERNEL=triton).
- SnapKV + 4-bit KV combined cache (kv_backend.py SnapKV4BitCache): up to ~16x
  compression vs fp16 full cache.
- MHC hyper-connections (rank=512, gate=0) + AttnRes (k=4, gates=0) + PIT
  wired into V3 losslessly.
