## 6. Model Architecture

- **ConfigurableResearchLLM** (`model_loader.py`): config-driven, weight tying, optional draft head, chunked CE, activation checkpointing.
- **ModularBlock**: swappable attention, FFN, normalization; activation checkpointing in `forward`.
- **Attention variants**:
  - `MultiHeadLatentAttention` — MLA with `kv_compression_dim` (default 128).
  - `DifferentialAttention` — learnable lambda, two Q/K groups.
  - `StandardSDPA` — standard causal RoPE attention.
  - `GroupedQueryAttention` — GQA with KV head repetition.
- **FFN:** `SwiGLUFFN` (8/3 d_model hidden dim).
- **Positional:** `RotaryEmbedding` with YaRN scaling parameters (`factor`, `original_max_position_embeddings`, `beta_fast`, `beta_slow`).
- **Norm:** `RMSNorm` or `LayerNorm`.

### Optional Architecture Plug-Ins
- `bitnet.py` — `BitLinear` ternary {-1,0,+1} weights; `convert_model_to_bitnet()`.
- `gateskip.py` — `GateSkipBlock` token-wise layer skipping; `add_gateskip_to_model()`.
- `mtp.py` — `MTPHead` / `MTPTrainer` for multi-token prediction.
- `moe.py` — `Router`, `Expert`, `MoELayer` top-k; `replace_ffn_with_moe()`.
- `chunked_ce.py` — `ChunkedLinearCrossEntropy` avoids materializing full `[B*T, V]` logits.
- `longrope2.py` — evolutionary LongRoPE2 scaling search.
- `entropy_abf.py` — Entropy-ABF 4x context extension.
- `paged_kv.py`, `medusa.py`, `eagle.py`, `kv_compress.py`, `ssa.py`, `mola.py`, `pma.py`.

### Fine-Tuning / Inference Modules
- `dora.py` — DoRA decomposition; `treelora.py` — tree LoRA.
- `fast_infer.py`, `inference_quant.py`, `spinquant.py`, `compile_wrapper.py`, `cuda_graph.py`.
- `serve.py` — OpenAI-compatible HTTP handler with Qwen chat template and tool-call parsing.

## 7. Data Pipeline

- `prep_data.py` streams FineWeb-Edu / Cosmopedia-v2 / Stack-Edu-Python mix and writes flat `uint32` binaries:
  - `research/data/train.bin` / `val.bin` (memory-mapped, EOS after each document).
- `generate_synthetic.py` produces prompt/completion JSONL from LM Studio local API.
- `merge_synthetic.py` merges per-teacher files (`lmstudio_*.jsonl`), optional dedup and domain balancing.
- `quality_score.py` scores on 6 dimensions (length, diversity, coherence, repetition, code, alignment) and can reorder by difficulty/length.
- `reformat_chat.py` converts plain JSONL to Qwen chat format with CoT prefixes for reasoning/math/coding.
- `dedup.py` uses MinHash + LSH for near-duplicate detection.
- `prep_tool_data.py` generates `tool_sft.jsonl` for tool-calling SFT.

### Data Formats
- **Plain synthetic JSONL:** `{"prompt": "...", "completion": "...", "domain": "...", "teacher": "..."}`
- **Chat JSONL:** `{"messages": [{"role": "user"}, {"role": "assistant"}], "domain": "..."}`
- **Scored JSONL:** adds `"_quality_score"` and `"_quality_scores"`.
- **Binary tokens:** `.bin` flat `uint32` with per-document EOS.
- **Checkpoints:** `.safetensors` preferred + `.meta.json` sidecar; `.pt` legacy.

## 8. Gigatoken Feature

- **Location:** `research/prep_data.py` (tokenizer wrapper) and `requirements.txt` (`gigatoken==0.9.0`, optional).
- **Three backends** controlled by `--tokenizer-backend`:
  1. `hf` — HuggingFace `AutoTokenizer` (default, no extra deps).
  2. `gigatoken-compat` — `gt.Tokenizer(hf_tok).as_hf()`; exact HF parity, ~30-40x faster.
  3. `gigatoken-native` — `gt.Tokenizer(model_name).encode_batch_list(texts)`; batched Rust, largest speedup on many-core CPUs; preserves per-document boundaries.
- `build_encoder()` always loads the HF tokenizer first for `eos_id` and `vocab_size` source-of-truth.
- `--encode-batch` default `512`; determines samples per encoder call.
- **Design note (BUG-004):** `gt.encode_files` was avoided because it returns a flat token stream with no document boundaries; `encode_batch_list` keeps boundaries so per-doc EOS insertion works.

## 9. Known Gotchas

- `triton-windows` needs the Windows cache-path patch; throughput goes from ~10,000 to ~13,300 tok/s.
- `Liger Kernel` crashes on RTX 5070 — use `chunked_ce.py` instead.
- `--chunked-ce` is **not** compatible with `--compile`.
- `gigatoken` is optional; `prep_data.py` falls back to HF if unavailable and backend is `hf`.
- Set `HF_TOKEN` in `.env` for higher Hub rate limits; `prep_data.py` sets `HF_HUB_DOWNLOAD_TIMEOUT=60`.
- Chat templates (`<|im_start|>user/assistant`) are critical for instruction tuning; `distill_synthetic.py` and `sft_align.py` support assistant-only loss masking.
- `safetensors` is the preferred checkpoint format for mmap loading and pickle safety.

## 10. Next-Agent Cheat Sheet

1. Read `AGENTS.md` for the exact verified command list.
2. Pick a config with `from research.config import get_config; cfg = get_config('360m_mla')`.
3. Load a model with `ModelLoader.build_model(cfg, checkpoint_path='...')`.
4. Tokenize data with `python -m research.prep_data --tokenizer-backend gigatoken-compat`.
5. Pre-train with `python -m research.train --config 360m_mla --steps ...`.
6. Distill with `python -m research.distill` or `python -m research.distill_synthetic`.
7. Align with `python -m research.sft_align` then `python -m research.dpo_align --method self-reward`.
8. Monitor progress with `python -m research.monitor` reading `research/checkpoints/distill_status.json`.
